# 🐾 SwipePets

Una app móvil desarrollada en Android Studio con Kotlin que te permite explorar imágenes de adorables mascotas, darles "me gusta" y gestionar tu lista de favoritas. Ideal para practicar conceptos de navegación, ViewModel, LiveData y RecyclerView en Android.

## 📱 Características

- 🖼️ Navegación por imágenes de mascotas con toques laterales.
- ❤️ Da "like" a tus mascotas favoritas.
- ⭐ Visualiza todas las mascotas que te han gustado.
- 📊 Indicador de progreso para cada mascota (barra por imagen).
- 🔄 Interacción fluida con LiveData y ViewModels.

## 🛠️ Tecnologías utilizadas

- Kotlin
- Android Jetpack (Fragments, ViewModel, LiveData)
- RecyclerView
- Navigation Component
- Material Design Components
